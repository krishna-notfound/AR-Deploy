## Owner decisions

1. **Hide the testing site from search? (ENV-SITE-07)** Options: (a) leave as is (public pages crawlable); (b) noindex everything until go-live. Prepared, not applied: (b1) hide from crawling only: replace `public/robots.txt` with `User-agent: *` / `Disallow: /` (does not remove already-indexed URLs). (b2) real noindex: add this rule at the end of `vercel.json` `headers` and keep the current robots.txt (a crawler must be allowed to fetch a page to see its noindex, so do not combine with `Disallow: /`):
   ```
   { "source": "/(.*)", "headers": [{ "key": "X-Robots-Tag", "value": "noindex, nofollow" }] }
   ```
   Undo either at go-live.
2. **Canonical domain.** Three hosts serve the same site (`sanctus.warpkit.online`, `builtbykrishna.dev`, `ar-deploy-sage.vercel.app`) and hosting will move to the client's Vercel. A `<link rel="canonical">`, `og:url`, and the absolute URLs in `public/sitemap.xml` and the `Sitemap:` line of `public/robots.txt` all depend on which one. Today they name `sanctus.warpkit.online`; change them at the move.
3. **Per-page link previews (OG title, description, image per catalogue or product).** Bots that do not run scripts only read `index.html`. Options: (a) accept the site-wide static preview now in `index.html`; (b) a Vercel middleware or function that rewrites head tags per route (a backend component, ADR-0015 forbids it unless the owner records an exception); (c) a build-time prerender of the fixed pages only (no new dependency possible without an ADR); (d) a Supabase Edge Function rendering preview HTML for bot user agents, routed by a Vercel rewrite (stays on Supabase, still needs an ADR). Same options for dynamic catalogue and product URLs in the sitemap.
4. **Real HTTP 404 for missing catalogues and products.** Needs a server-side lookup (same options as 3). Until then the pages are noindex only.
5. **Collections in the sitemap.** `/collections/*` slugs are edited by the client in the Website Editor, so a static sitemap cannot list them correctly; only the four fixed pages are listed.
6. **Flip the rest of the CSP to enforced.** After a Supabase-mode click-through and a phone test (Scene Viewer, Quick Look, WebXR), add `default-src 'self'; connect-src 'self' https://*.supabase.co https://www.gstatic.com https://raw.githubusercontent.com blob: data:; img-src 'self' data: blob: https://*.supabase.co https://images.unsplash.com; media-src 'self' blob:` to the two enforced rules and drop the report-only header (ADR-0076). Note Vercel Preview deployments lose their toolbar scripts under the enforced `script-src` (production unaffected).
